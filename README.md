# GaveView｜Kotlin / Android Custom View 学習サンプル

岡崎市・東岡崎のプログラミング教室 **[MYマナビスタイル](https://wkstyle.jp/school)** の開発コース教材です。  
Kotlin と Android の Custom View（自作 View）を使い、画面タッチに合わせてキャラクターが歩いてくる小さなゲーム画面を作ります。

このリポジトリは、小学生〜大人まで学べる教室の「その先」である **テキストプログラミング / Androidアプリ開発** の公開サンプルです。教材を進めることより、自分で考えて作れるようになることを目指しています。

- 対象: 中学生〜大人（意欲があれば小学生も可）
- 言語: Kotlin
- 内容: Canvas 描画、タッチ操作、アニメーション、座標計算
- 教室: 愛知県岡崎市（東岡崎駅徒歩圏内・康生町エリア）
- 運営: プログラミングワークスタイル株式会社（現役の開発会社）

無料体験・最新のコース案内は公式サイトをご覧ください。  
**[岡崎市・東岡崎のプログラミング教室 MYマナビスタイル](https://wkstyle.jp/school)**

## このアプリでできること

画面をタッチすると、水色のキャラクターがそこまで歩いてきます。タッチした場所には波紋エフェクトが出ます。

学べるポイントは次のとおりです。

1. XML レイアウトではなく、Kotlin で View を自作する
2. `Canvas` と `Paint` で背景・キャラクター・文字を描く
3. `onTouchEvent` でタップ座標を受け取る
4. 目標地点へ少しずつ近づける移動（ベクトル計算）
5. `postInvalidateOnAnimation()` でアニメーションを回す

メインの実装は [`app/src/main/java/jp/wkstyle/pg/gaveview/MainActivity.kt`](app/src/main/java/jp/wkstyle/pg/gaveview/MainActivity.kt) です。コメントは教室の授業でも読めるよう、日本語で書いてあります。

## 実行方法

必要なもの:

- Android Studio
- JDK 11 以上（Android Studio 付属の JBR で可）
- Android SDK（compileSdk 35）
- 実機またはエミュレータ（minSdk 29 / Android 10 以上）

手順:

1. このリポジトリをクローンする
2. Android Studio でフォルダを開く
3. Gradle 同期が終わるのを待つ
4. 実機またはエミュレータを選び、`app` を実行する

`local.properties` は各環境の Android SDK パスを書くファイルです。公開リポジトリには含めません。Android Studio が自動生成します。

## コードの見どころ

| 処理 | 役割 |
| --- | --- |
| `GameView` | 画面全体を描く自作 View |
| `onDraw()` | 背景、グリッド、波紋、キャラクター、案内文字を描く |
| `onTouchEvent()` | タッチ位置を目標座標にする |
| `updateCharacterPosition()` | 現在地から目標へ一定速度で移動する |
| `drawRipple()` | タッチした場所に広がる輪っかを描く |

プログラミング教室では、このサンプルを入口にして次のような発展ができます。

- キャラクターの見た目やスピードを変える
- 障害物やゴールを追加する
- スコアや効果音を足す
- 自分のアイデアで小さなゲームにする

MYマナビスタイルでは、決められた教材をこなすことより、「考える → 試す → 直す → 完成させる」ことを大切にしています。

## よくある質問

**このリポジトリは何のための公開教材ですか？**  
岡崎市のプログラミング教室 MYマナビスタイルで扱う、Kotlin / Android の Custom View 入門用サンプルです。ゲーム画面を通して、描画・タッチ・移動の基本を学びます。

**パソコン未経験でも教室に通えますか？**  
はい。基礎コースではタイピングや基本操作から始められます。開発コース（本リポジトリの内容）は表示が英語中心のため中学生以上を推奨しますが、意欲があれば小学生も相談できます。

**Kotlin や Android アプリ開発は教室で学べますか？**  
学べます。開発コースでは Android アプリ（Kotlin / Android Java）をベースに、環境構築から現役のアプリ開発者が指導します。

**英語教室もありますか？**  
あります。MYマナビスタイルはプログラミング教室に加えて、岡崎市・東岡崎の英語教室も運営しています。英語教室の学び方のひとつが英語×プログラミングで、暗記中心ではなく英語を「使う道具」として体感します。英語が苦手な子や、英語教室が続かなかった子にも向いています。

**無料体験はありますか？**  
あります。内容や日程は [公式サイト](https://wkstyle.jp/school) からお問い合わせください。
